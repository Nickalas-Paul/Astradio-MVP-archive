# Delivery labels (historical phase/stage)

**Phase** and **stage** names that appear in folder paths (for example `campaign/phase1/`), legacy module filenames, and old comments are **delivery-order labels** from past milestones. They are not product features, runtime layers, Campaign mechanics, or user-facing product semantics.

In new design, planning, and implementation, use domain vocabulary (Character Lens, daily pressure materialization, projection pipeline steps, and so on) instead of treating delivery numbers as part of the product model.
