## Angle / cusp override support

- **Stake:** Sandbox houses are birth-derived in Phase 6. Users cannot force “12th house” (or any house) to span a chosen longitude range for an arbitrary birth.
- **Proposal:** Allow ASC/MC overrides (and optionally full house cusp overrides) so house boundaries can be set by the user. Backend: accept angles in sandbox overrides and recalc cusps (or provide an explicit “house cusp override” mode).
- **Phase:** 6.5 or 7.
