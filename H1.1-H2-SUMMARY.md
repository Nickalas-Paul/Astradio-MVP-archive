# Phase-3 Hardening H1.1/H2 - Deliverables Summary

## North Star Achieved
**One deterministic, observable `/api/compose` pipeline** that produces audio + text from the same control-surface payload, enforces Unified Spec v1.1, is deterministic (seed = controls.hash) end-to-end, meets latency/observability requirements, and has comprehensive E2E testing.

## H1.1 - Overlay Δ Guardrails & Determinism Normalizer

### Centralized Overlay Δ Thresholds
- **File**: `vnext/explainer/overlay-delta.ts`
- **Function**: `shouldContrast(kind, deltaAbs)` with exact thresholds:
  - `step_bias ≥ 0.10`
  - `syncopation_bias ≥ 0.15` 
  - `density_level ≥ 0.20`
- **Integration**: `vnext/explainer/text-realizer.ts` uses centralized guard
- **Test Results**: 
  - ✅ Δ = 0 → no contrast text
  - ✅ Δ below thresholds → no contrast text
  - ✅ Δ above thresholds → contrast text present

### Determinism Normalizer
- **Files**: `vnext/scripts/determinism-normalizer.ts`, `vnext/scripts/e2e-determinism.ts`
- **Exclusions**: `artifacts.timestamp`, `audio.latency_ms`
- **Test Results**: 5× identical requests → byte-identical responses (normalized)

## H2 - Logger File Sink & Test Override

### Logger Rollover
- **File**: `vnext/logger.ts`
- **Features**: 10MB size cap, 3-file retention, automatic rollover
- **Log Fields**: `controls_hash`, `seed_used`, `template_id`, `latency_ms.*`, `gate_scores`, `fail_closed_text`, `artifacts.*`
- **Dashboard**: 15.2% fail-closed rate (5/33 requests)

### Test Override Mechanism
- **File**: `vnext/api/compose.ts`
- **Feature**: `testOverride.forceFail` for reliable fail-closed testing
- **Test Results**: 
  - ✅ `short=""` when calibrated.overall=false
  - ✅ `template_id="v1.fail.00"` for fail-closed
  - ✅ `long` and `bullets` contain only knob hints
