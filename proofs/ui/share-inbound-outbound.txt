## Inbound Share (Link → Read-Only Player)
- **URL**: `/share/abc123def456`

- **Wheel Display**: Static snapshot matching original PASS
- **Player Controls**: Play/pause/seek only (no compose/edit) PASS

## Privacy & Safety
- **PII Redaction**: Birth data not in shared URLs PASS
- **Consent Check**: User must opt-in to sharing PASS
- **Kill-Switch**: Global disable works when enabled PASS
- **Scope Control**: Private compositions not shareable PASS

## Error Handling
- **Invalid ID**: 404 with helpful message PASS
- **Expired Link**: 410 with re-share option PASS
- **Private Composition**: 403 with login prompt PASS
- **Network Error**: Retry with backoff PASS
