# Drum and sample assets

- **drums/808**, **drums/909**, **drums/jazz**, **drums/orch**: Kick, snare, hat one-shots. Used by the Browser Performance Engine (House pack uses 808 by default).
- **house**: Optional future folder for dedicated house kit (kick, clap, hh_closed, hh_open). Paths in the genre pack can be updated to `/audio/samples/house/` when present.
- **Licensing**: Ensure all samples are properly licensed for use in the app. Replace with placeholders or curated packs as needed; engine falls back to synth drums if samples fail to load.
