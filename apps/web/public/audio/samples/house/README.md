# House Tonal Samples

Place house-style tonal samples here for sample-first voicing.

## Bass (3–8 notes or single one-shot)
- Option A: Single short bass one-shot (e.g. `bass_C2.wav`) that can be pitch-shifted. Engine uses C2 as base.
- Option B: Multiple notes across octaves: `bass_C1.wav`, `bass_F1.wav`, `bass_A1.wav`, `bass_C2.wav`, etc.
- Recommended: Sub-bass or 808-style bass, C1–C2 range.

## Harmony (3–8 chord stabs or single stab)
- Option A: Single chord stab sample (e.g. `stab_C4.wav`) that pitches well.
- Option B: Multiple stabs: `stab_C3.wav`, `stab_Eb3.wav`, `stab_G3.wav`, etc.
- Recommended: Short house stab, filtered, ~200–400ms.

## Melody (3–8 plucks or single pluck)
- Option A: Single pluck sample (e.g. `pluck_C4.wav`) that pitches well.
- Option B: Multiple plucks across octaves.
- Recommended: Bright pluck, ~80–150ms decay.

Paths used when present:
- `/audio/samples/house/bass_C2.wav` (single) or note-keyed map
- `/audio/samples/house/stab_C4.wav` (single) or note-keyed map
- `/audio/samples/house/pluck_C4.wav` (single) or note-keyed map
